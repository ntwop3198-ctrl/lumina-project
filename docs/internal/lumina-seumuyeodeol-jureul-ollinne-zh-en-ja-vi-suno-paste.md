# 呈上二十八条 — KO·ZH·EN·JA·VI Suno 붙여넣기

곡 설명 칸은 비운다. **최승로 헌정.** **#3 위인 헌정 · 3-1 역사인물(한국·고전서사).**  
브리지 5줄째 **구소구고구기, 밖에서 찾지 않고**는 다섯 버전 모두 한글 그대로.  
진공묘유는 넣지 않는다. 한자·영역·한월음으로 풀지 않는다.

[Verse 1]
