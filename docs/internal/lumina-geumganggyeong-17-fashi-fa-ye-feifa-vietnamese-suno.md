## Style

```
Vietnamese acoustic meditative folk ballad, soft moktak woodblock, nylon guitar, daegeum, calm and deep, guitar drops to solo daegeum on bridge, warm calm male Vietnamese vocal, 70 BPM, Vietnamese only
```

## Exclude Styles

```
EDM, trap, rap, autotune, metal, screaming, trot, female vocal, choir
```
