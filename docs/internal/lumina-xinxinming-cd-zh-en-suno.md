# 신심명 CD — 중국어·영어 수노 붙여넣기

> **7-1 불교** · 신심명 CD · 승찬 대사
> 수노 곡 설명 칸은 비운다. 스타일 칸의 긴 문장은 업로드본 그대로 둔다.
> 12곡은 한 장이다. 02 · 04 · 06 · 08 · 10은 여성, 나머지는 남성이다. 11곡 후렴만 혼성 합창이 붙는다.
> 다양성은 휴대폰 화면 정상, 노트북 화면 보통. 개인화는 끔.

호흡은 한 숨에 부를 수 있는 짧은 줄이다. 템포는 곡마다 원안 BPM을 유지한다. 악기는 업로드본을 따른다. 가야금, 대금, 거문고, 통기타, 싱잉볼이다.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 칸 | `7-1 불교`. 신심명 CD |
| 브리지 | 6줄. 1·2행은 그 곡의 말. 3행은 그 곡의 작은 것, 4행은 피하지 않는 고생 |
| 브리지 5행 | 중국어 `求小求苦求己, 不向外求` · 영어 `Seek the simple, face the hard, seek within` |
| 브리지 6행 | `真空妙有` · `True emptiness, wondrous being` |
| 한글 시그니처 | 가사에는 넣지 않음. 한글로 통일할 때만 5행을 `구소구고구기, 밖에서 찾지 않고`로 바꾼다 |
| 기호 | 가사 칸에 괄호, 따옴표, 느낌표, 말줄임표, 쉼표 없음. 시그니처 쉼표만 유지 |
| 영어 | 아포스트로피 없음 |
| 화자 | 부르는 칸 아래 `[Female]` 또는 `[Male]`. 빈 간주에는 없음 |
| 02 | 빈손이 하늘을 담는다는 말과 오늘 하늘이 맑다는 말은 이 한 마음으로 낮춤 |
| 03 | 털 하나에 하늘이 다 든다는 말과 천지가 하나가 된다는 말은 이 한 걸음으로 낮춤. 털끝의 어긋남은 경의 구절로 둠 |
| 04 | 한 하늘 아래의 구름, 다툼이 그치면 꽃이 핀다는 말은 뺌 |
| 05 | 허공이 온 세상을 담는다는 말과 오늘도 둥글다는 말은 뺌. 원동태허는 경의 구절로 둠 |
| 07 | 참이 앉아 있다는 말은 이 한 걸음으로 낮춤 |
| 10 | 흐린 날도 환하고 오늘도 밝은 아침이라는 말은 눈을 뜨는 행동으로 낮춤 |
| 11 | 한 사람이 온 세상이고 길이 다 열린다는 말은 물 한 방울과 한 걸음으로 낮춤. 일즉일체는 경의 구절로 둠 |
| 12 | 천 년 뒤 오늘도 길이 된다는 말은 아직 읽는 사람이 있다는 말로 낮춤. 죽음이라는 낱말은 넣지 않음 |

채팅에 붙은 01 · 04부터 12의 초안은 쓰지 않았다. 구정, 적자, 고금, 동소, 번체 제목은 넣지 않았다. 02와 03은 채팅에는 없고 업로드 문서에 있어 같은 CD로 넣었다.
