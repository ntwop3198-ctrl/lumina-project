## Title

```
千の山 万の川
```

문서 한글: **산 넘고 물 건너도** · 보컬 **남성** — 따뜻하고 구수한 톤, 1절 기차역에서 목이 메듯 올라갔다가 2절은 통화하며 웃듯 풀어지게

## Style

```
Japanese campus folk ballad, warm male vocal, mid-tempo gentle sway, warm analog tape saturation, fingerpicked acoustic guitar, dizi and soft harmonica, light brushed drums and gentle strings, Japanese vocals, short Korean chant in bridge
```

## Exclude Styles

```
EDM, trap, rap, heavy drums, autotune, belting, rock guitar, Cantonese, female vocal, enka
```
