# 正在什么都不做 — KO·ZH·EN·JA·VI Suno 붙여넣기

곡 설명 칸은 비운다. 브랜드송 해당 없음.  
브리지 **구소구고구기** · **진공묘유** 는 가사 본문 행 (대괄호 없음).  
KO 2절은 **장롱 모서리** (업로드 오타 `장롯` 교정).  
가사에 fade 태그를 넣지 않는다. 하모니카 페이드는 스타일 한 줄.
