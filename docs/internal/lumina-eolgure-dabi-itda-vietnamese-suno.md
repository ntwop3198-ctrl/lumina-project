# 얼굴에 답이 있다 — 베트남어 수노 붙여넣기

> **5-2 성인 유머** · 얼굴에 답이 있다 · 남성 · 베트남어
> 수노 곡 설명 칸은 비운다.
> 다양성은 휴대폰 화면 정상, 노트북 화면 보통. 개인화는 끔.

관상 너스레다. 브리지 6행에 진공묘유를 넣지 않는다. 이 곡 잠금은 다섯 언어 모두 5행을 한글로 둔다. 베트남어로 시그니처를 옮기지 않는다.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 칸 | `5-2 성인 유머` |
| 브리지 | 6줄. 1·2행은 관상 너스레. 3행은 거울 속 작은 주름. 4행은 못난 날을 피하지 않음. 6행은 그래도 맞는 말 같다는 너스레 |
| 브리지 5행 | `구소구고구기, 밖에서 찾지 않고` 한글 그대로 |
| 진공묘유 | 넣지 않음 |
| 화자 | 부르는 칸과 말하는 칸 아래 `[Male]`. 금관 칸과 페이드에는 없음 |
| 웃음 소리 | 하, hà hà, Ha ha ha는 뺌. 웃는다는 말은 남김 |
| 오늘 | 오늘 짓는 웃음은 이 곡의 답이라 남김 |

원본은 `humor-twelve` 잠금본의 베트남어 가사다. 제목은 `Câu Trả Lời Trên Gương Mặt`로 고정한다.
