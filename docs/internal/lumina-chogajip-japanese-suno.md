## Title

```
藁ぶきの家
```

문서 한글: **초가집** · 보컬 **남성** — 연륜 있는 낮고 따뜻한 톤, 옛집을 더듬듯 담담하게

## Style

```
Japanese folk ballad, warm acoustic guitar, gentle daegeum flute, soft gayageum, sparse percussion, aged warm male vocal, nostalgic and earthy, rural home mood, 68 BPM, Japanese vocals, short Korean chant in bridge
```

---

## Exclude Styles

```
EDM, rap, autotune, female vocal, choir, epic orchestra, trot vibrato, fast dance beat, tragic mood, heavy reverb, enka
```

고급 설정: 기이함 **30%** · 스타일 영향 **65%** · 다양성 보통 · 개인화 끔

수노 v6 맨 위 곡 설명 칸은 **비운다.**
