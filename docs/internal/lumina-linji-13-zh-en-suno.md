# 임제 13곡 — 중국어·영어 수노 붙여넣기

> **7-1 불교** · 진공묘유 · 구소구고구기  
> 수노 곡 설명 칸은 비운다. 브랜드송 해당 없음.  
> 13곡은 한 연작이다. 보컬은 모두 남성. 다양성은 정상, 개인화는 끔.

호흡은 한 숨에 부를 수 있는 짧은 줄이다. 템포는 곡마다 원안 BPM을 유지한다.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 브리지 | 6줄. 3행 求小, 4행 求苦 |
| 브리지 5행 | 중국어 `求小求苦求己, 不向外求` · 영어 `Seek the simple, face the hard, seek within` |
| 브리지 6행 | `真空妙有` · `True emptiness, wondrous being` |
| 한글 시그니처 | 가사에는 넣지 않음. 한글로 통일할 때만 5행을 `구소구고구기, 밖에서 찾지 않고`로 바꾼다 |
| 괄호 · 따옴표 · 느낌표 | 가사 블록에 없음. 연출은 영어 대괄호만 |
| 검사어 | 칼 · 피 · 죽음은 다른 말로 옮김. 온 우주는 十方 · all directions |
| 화자 | 각 섹션 아래 `[Male]` |

앞에 온 「临济的一喝 / Linji's Roar」초안은 07 临济喝으로 합쳤다. 초안의 `真空妙유`, `Vacuum and marvelous being`, 칼날·한 칼·부수는 말은 넣지 않았다.

08 逢佛杀佛은 제목만 원문을 둔다. 가사에는 죽이라는 말을 넣지 않고 放下 / let go로 둔다. 제목이 걸리면 `遇见就放下` / `If You Meet the Buddha, Let Go`를 쓴다.
