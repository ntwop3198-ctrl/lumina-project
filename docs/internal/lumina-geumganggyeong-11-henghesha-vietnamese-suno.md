## Style

```
Vietnamese acoustic meditative folk ballad, soft moktak woodblock, nylon guitar, daegeum, vast and flowing like a great river, guitar drops to solo daegeum on bridge, warm calm male Vietnamese vocal, 70 BPM, Vietnamese only
```
