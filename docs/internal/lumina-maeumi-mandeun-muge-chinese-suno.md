## Lyrics (v1)

```
[Intro]
[Low strings]
原以为只是一句老话
活过才知道 化成了重量

[Verse 1]
都说万事皆由心生
我只当是一句文字匆匆走过
表里不一的日子一天天堆积
我看见那重量总会留在某处

[Verse 2]
心不安 夜也难安
心沉重 脚步也沉重
藏着压着的日子越是漫长
那份担子就悄悄渗进哪里

[Pre-Chorus]
该怪的不只是风
怎样用这颗心
有时会改变我脚下的路
只是不知道那是否就是全部

[Chorus]
一切唯心造 心会造出重量
藏起的心 藏多少就有多重
安然的心 安多少就有多轻
那重量有时会留在脚步上
管好这颗心 就是管好自己

[Verse 3]
好像骗过了谁
骗得最久的却是我自己
如今我开始听一听身体的话
从脚步里读懂心留下的重量

[Bridge]
我还想再握住什么
放下一些 问问自己
不再怪谁 回头看看自己
空出来的地方 呼吸慢慢平稳
求小求苦求己, 不向外求
心若轻了 脚步也轻

[Chorus]
一切唯心造 心会造出重量
藏起的心 藏多少就有多重
安然的心 安多少就有多轻
那重量有时会留在脚步上
管好这颗心 就是管好自己

[Outro]
[Lingering strings]
看脚步就看见心
看心就看见走过的地方
```
