# 매운맛의 반란 — bhc 브랜드송 네 언어 수노 붙여넣기

> **13 브랜드 헌정** · bhc  
> 수노 곡 설명 칸은 비운다.  
> 보컬은 남성. 밝고 힘찬 톤, 꺾기는 살짝.  
> 다양성은 정상, 개인화는 끔. 노트북 화면의 다양성은 보통으로 보인다.  
> 기이함 40% / 스타일 영향 70%.

불교 곡이 아니다. 진공묘유는 넣지 않는다. 상호가 있으므로 칸은 13 브랜드 헌정이다.

뿌링클은 매운맛이 아니라 치즈 시즈닝이다. 인트로에서 매운맛의 반란과 뿌링클을 한 줄로 잇지 않았다. 치즈볼과 Bburinkle은 1절에 둔다. 표기는 Bburinkle.

앞에 온 초안의 辛辣的叛逆, Purincle, 哎西库, 브리지가 6줄이 아닌 본은 여기로 합치지 않았다.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 브리지 | 6줄. 3행은 작은 닭 한 마리, 4행은 쓴 날을 피하지 않음 |
| 브리지 5행 | 중국어 `求小求苦求己, 不向外求` · 영어 `Seek the simple, face the hard, seek within` · 일본어 `小を求め 苦を求め 己を求め, 外に求めず` · 베트남어 `Cầu điều giản dị, đương đầu gian khó, tìm trong chính mình` |
| 브리지 6행 | 늘 처음처럼 새롭게 나아감. 진공묘유는 없음 |
| 한글 시그니처 | 가사에는 넣지 않음. 한글로 통일할 때만 5행을 `구소구고구기, 밖에서 찾지 않고`로 바꾼다 |
| 괄호 · 따옴표 · 느낌표 | 가사 블록에 없음. 잦아듦은 `[Fade Out]` |
| 화자 | 부르는 줄 아래 `[Male]` |
| 파트너 | 가맹점과 함께 걷는 줄만 둔다. 숨은 비용 말은 없다 |

한글 시그니처와 언어별 시그니처를 한 브리지에 같이 넣지 않는다.

한국어 브리지 원안:

화려한 길보다 거친 길 택해 / 남들이 웃어도 우리 길 갔네 / 작은 닭 한 마리에 정성을 담고 / 쓴 날도 피하지 않고 견뎌왔지 / 구소구고구기, 밖에서 찾지 않고 / 늘 처음처럼 새롭게 나아가네

각 언어마다 수노 칸은 네 개다. 곡 설명은 비운다.

1. 제목 코드 블록.
2. 스타일 코드 블록.
3. 제외 코드 블록.
4. 가사 코드 블록.

꼬리표 칸에는 `13 브랜드 헌정`을 쓴다. bhc는 부메모다.

5행을 한글로 통일할 때만 `구소구고구기, 밖에서 찾지 않고`로 바꾼다. 언어별 시그니처와 한글 시그니처를 함께 넣지 않는다.
