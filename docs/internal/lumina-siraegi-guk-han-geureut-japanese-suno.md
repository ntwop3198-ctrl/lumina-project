## Lyrics (v1)

```
[Intro]
[Soft fingerpicked guitar, distant harmonica]

[Verse 1]
幼い頃の夕飯には毎日あの汁
干し菜の浮かんだテンジャン汁一杯
肉のおかずの家がただうらやましくて
スプーンをいじってだだをこねた

[Verse 2]
天井にはメジュがずらり 鼻をつく匂い
軒下には干し菜が風に揺れて乾く
かまどの前にしゃがんだ母さん
真っ白な湯気の中でたくさん食べなと言った

[Chorus]
シレギ汁一杯 あの頃はわからなかった
飽きたあの味がこんなに恋しくなるなんて
あの店この店 探し歩いても
食べられはするけど あの味じゃない

[Verse 3]
今のテンジャンは甘くてやさしいけれど
腹の底までほどいてくれたあの味がない
わらで寝かせて甕で熟成させて
一年二年待ったあの味はどこへ

[Bridge]
同じ土鍋で同じように煮ても
あの手の味だけはまねできない
仕込みの手 火をおこしたあの手
あの手が入れたのはテンジャンだけじゃなかった

[Final Chorus]
[Soft strings enter]
シレギ汁一杯 今やっとわかる
あのひとさじに何が込められていたか
もう二度と食べられない母さんの味
今日もひとさじすくって あの台所を思い出す

[Outro]
幼い頃あんなに嫌いだったあの汁が
今はいちばん食べたい食卓になった
[Harmonica fades out]
```
