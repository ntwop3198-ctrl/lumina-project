# 哎呀真是 — KO·ZH·EN·JA·VI Suno 붙여넣기

곡 설명 칸은 비운다. 브랜드송 해당 없음.  
브리지 **구소구고구기** · **진공묘유** 는 가사 본문 행 (대괄호 없음).  
영어 말끝 `stay in my mind` · `so complicated` · `Oh well` · `that's life` 는 번역하지 않는다.  
KO 3절은 **옅어지더라** (업로드 오타 `업어` 교정).
