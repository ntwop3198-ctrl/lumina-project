## Lyrics (v1)

```
[Intro]
[Low strings]
ただの古い言葉だと思っていた
生きてみたら重さとして残った

[Verse 1]
すべては心から始まるという言葉
ただの文字だと思って通り過ぎた
表と裏が違う日々が積もると
その重さがどこかに残るのを見た

[Verse 2]
心が安らかでなければ夜も安らがない
心が重ければ足取りも重い
隠して押さえた日々が長くなるほど
その荷はどこかへ染み込んでいく

[Pre-Chorus]
責めるべきは風だけじゃない
心をどう使ってきたかが
歩く道の手ざわりを変えることもある
ただそれがすべてかはわからない

[Chorus]
すべては心がつくる 心がつくる重さがある
隠した心は隠したぶん重く
安らかな心は安らかなぶん軽い
その重さが足取りに残ることもある
心を整えることが自分を整えること

[Verse 3]
誰かをだましたようでも
いちばん長くだましたのは自分だった
今は体の声を少し聴いている
心が残した重さを足取りで知る

[Bridge]
まだ何をつかもうとしていたのか
少し手放して自分に問いかける
人を責めずに自分を見つめる
空いた場所で息が少し整う
小を求め 苦を求め 己を求め, 外に求めず
心が軽ければ足取りも軽い

[Chorus]
すべては心がつくる 心がつくる重さがある
隠した心は隠したぶん重く
安らかな心は安らかなぶん軽い
その重さが足取りに残ることもある
心を整えることが自分を整えること

[Outro]
[Lingering strings]
足取りを見れば心が見えて
心を見れば生きてきた場所が見える
```
