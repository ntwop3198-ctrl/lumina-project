# Suno 매대 — 전체 축

> **2026-10-03** · 한 문서 · Cursor 멘토  
> 규칙: `.cursor/rules/lumina-suno-shelf-taxonomy.mdc`  
> 10·12 이름 폐기 기록: `lumina-axis-10-12-taxonomy-lock.md`  
> 브랜드송은 상호가 있을 때만. 효능이 아니다.

곡을 잠글 때 **이 파일만** 본다. 옛 트리(#1–#14)와 10·12 새 이름은 여기서 이기지 못한다.

---

## 멘토 한 줄

> **쓰는 칸은 열두 개가 아니다. 잠긴 칸만 번호+이름으로 쓴다. 없는 칸을 만들지 않는다.**

향화 팀장:

> 아이 재우는 곡은 **10-4**, 어른 잠 곡은 **11-4**.

---

## 이 표를 읽는 법

| 표시 | 뜻 |
|------|-----|
| **잠금** | 번호+이름이 정본. 곡 문서에 이 이름으로 적는다. |
| **쓰는 칸** | 예전에 곡을 넣었다. 이름을 바꾸지 않는다. 새 칸을 더 열지 않는다. |
| **미잠금** | 번호만 떠 있다. 이름을 붙이지 않는다. |
| **없음** | 칸이 없다. 숫자를 채우려고 열지 않는다. |
| **폐기** | 붙였다가 버렸다. 다시 쓰지 않는다. |

## 금지

- 없는 칸을 만들어 곡 수를 맞추지 않는다.
- 수면·스트레스·활력을 **치료·효능**으로 적지 않는다.
- 11-4에 아이 자장가를 넣지 않는다. 10-4에 어른 잠을 넣지 않는다.
- Genesis 랜딩의 은유 열한 축과 **번호를 섞지 않는다.**
