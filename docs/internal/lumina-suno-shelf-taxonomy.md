## 구 파일

예전 11축 시절 곡 파일 코드는 **바꾸지 않는다**.

- 파일 코드 **6-x** → 내용은 지금 **7축 영성·각성**일 수 있다.
- 파일 코드 **10-x** → 내용은 지금 **11축 건강·수면**일 수 있다.
- 꼬리표 「1-3 없음」「7-1 없음」「13 없음」「4-2 안부」「1-2 이별」「10-4 아이 재움」이 남아 있어도 **파일은 그대로** 둔다. 새로 붙이는 꼬리표만 정본 이름을 쓴다.

1집은 확정. 새 곡은 2집 뒤에 넣는다.

## 가사 시그니처 (새 곡만 · 2026-10-06)

정본 `lumina-music-14-axis-shelf.md`와 같다. 옛 곡은 고치지 않는다. 「한자 쓰지 않음」「한글 전용」을 중국어·영어·일본어 새 곡에 적용하지 않는다.

| 노래의 언어 | 브릿지 5줄째 |
|-------------|--------------|
| 한국어 | 구소구고구기, 밖에서 찾지 않고 |
| 중국어 | 求小求苦求己, 不向外求 |
| 영어 | Seek the simple, face the hard, seek within |
| 일본어 | 小を求め 苦を求め 己を求め, 外に求めず (원어민 확인 뒤 확정) |

베트남어 줄은 아직 잠그지 않았다. 새로 만들지 않는다. 7-1이 아닌 새 곡에는 위 표의 시그니처 줄만 넣고 진공묘유는 넣지 않는다.

## 금지

- 정본에 없는 칸을 만들지 않는다. 애매하면 표시만 한다.
- 장르를 축으로 올리지 않는다.
- 수면·스트레스·활력·태교를 **치료·효능**으로 적지 않는다. 코르티솔·옥시토신 같은 말을 곡 설명의 효능으로 쓰지 않는다.
- 11-4에 아이 자장가를 넣지 않는다. 10-4에 어른 잠을 넣지 않는다.
- 진공묘유는 **7-1 불교** 새 곡에서만 넣는다. 노래의 언어를 따른다. 옛 곡의 시그니처는 파일에서 빼지 않는다.
- 새 곡 브릿지 시그니처는 **노래의 언어**. 표의 시그니처 줄은 한 글자도 바꾸지 않는다. 「한자 쓰지 않음」「한글 전용」을 모든 언어에 적용하지 않는다. 한국어 곡만 한글 줄. 옛 곡은 그대로 둔다.
- Genesis 랜딩 은유 열한 축과 번호를 섞지 않는다.
- **1-3이 열렸다고 4-2를 비우지 않는다.** 4-2는 실제 특정인을 두고 만들었거나 부탁받은 곡만. 가사에 「너」나 「당신」이 있다는 것만으로 4-2에 넣지 않는다.
