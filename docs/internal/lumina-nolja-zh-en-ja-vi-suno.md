# 놀자 — 중국어·영어·일본어·베트남어 수노 붙여넣기

> **11-1 신체·활력** · 놀자 · 남성
> 수노 곡 설명 칸은 비운다. 스타일 칸은 업로드본 그대로 둔다.
> 다양성은 휴대폰 화면 정상, 노트북 화면 보통. 개인화는 끔.

놀이로 부르는 곡이다. 불교 곡이 아니라 브리지 6행에 진공묘유를 넣지 않는다. 5행만 언어별 시그니처다.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 칸 | `11-1 신체·활력`. 정본 메모의 놀이 곡 |
| 브리지 | 6줄. 1·2행은 계획 없이 나가는 말. 3행은 문 앞 슬리퍼 한 켤레. 4행은 유치하다는 말을 피하지 않음. 6행은 한 소리 지르고 나감 |
| 브리지 5행 | 중국어 `求小求苦求己, 不向外求` · 영어 `Seek the simple, face the hard, seek within` · 일본어 `小を求め 苦を求め 己を求め, 外に求めず` · 베트남어 `Cầu điều giản dị, đương đầu gian khó, tìm trong chính mình` |
| 진공묘유 | 넣지 않음 |
| 한글 시그니처 | 가사에는 넣지 않음. 한글로 통일할 때만 5행을 `구소구고구기, 밖에서 찾지 않고`로 바꾼다 |
| 기호 | 가사 칸에 괄호, 따옴표, 느낌표, 말줄임표, 쉼표 없음. 시그니처 쉼표만 유지 |
| 영어 | 아포스트로피와 줄임말 없음. Let us play |
| 화자 | 부르는 칸 아래 `[Male]`. 인트로의 악기 칸에는 없음 |
| 떼창 | 스타일 칸의 떼창은 보컬 메모에 둠. 짧은 놀자 외침은 무리가 받아 부른다 |
| 오늘 | 오늘 실컷 놀자는 이 한 번으로 낮춤 |
| 온 세상 | 어린 시절 그 말이 온 세상이었다는 말은 하루를 채운 한 마디로 낮춤 |
| 웃음 소리 | 하하, ha ha, ハハハ는 뺌 |
| 죽음 | 死死와 dead honest는 꽉 참고, 숨기지 않고 말하는 것으로 바꿈 |
| 마지막 농담 | 순자, 맹자, 노자, 장자는 놀자는 말의 농담으로 둠. 7-2 가르침 곡이 아님 |

`/tmp/lumina_ml/part3.py`는 이 환경에 없었다. 업로드된 suno.md의 놀자 한 곡, 네 언어를 정리했다.
