## Title

```
산 넘고 물 건너도
```

문서 원본: **千山万水情谊在** · 보컬 **남성** — 따뜻하고 구수한 톤, 1절 기차역에서 목이 메듯 올라갔다가 2절은 통화하며 웃듯 풀어지게

---

## Style

```
Korean campus folk ballad, warm male vocal, mid-tempo gentle sway, warm analog tape saturation, fingerpicked acoustic guitar, dizi and soft harmonica, light brushed drums and gentle strings, Korean only
```

---

## Exclude Styles

```
EDM, trap, rap, heavy drums, autotune, belting, rock guitar, Cantonese, female vocal, English vocals
```

고급 설정: 기이함 **20%** · 스타일 영향 **70%** · 다양성 보통 · 개인화 끔

수노 v6 맨 위 곡 설명 칸은 **비운다.**
