## Lyrics (v1)

```
[Intro]
[Soft moktak and nylon guitar]

[Verse 1]
Fill the whole world with treasure
and give it all to others
the blessing born of that
would it be great

[Verse 2]
It would, World-Honored One
that blessing is great indeed
if merit had a substance
the Tathagata would not call it great

[Pre-Chorus]
Because it has no substance
he calls it great

[Chorus]
Merit has no substance
held, a handful, let go, the sky
with no vessel to contain it
it grows without an end
Merit has no substance
the more you give, the fuller it gets

[Verse 3]
The well in the heart of my home village
the whole town drew from it by the bucket
yet overnight it filled again
and never once ran dry

[Pre-Chorus]
Because it has no substance
he calls it great

[Chorus]
Merit has no substance
held, a handful, let go, the sky
with no vessel to contain it
it grows without an end
Merit has no substance
the more you give, the fuller it gets

[Bridge]
[Guitar drops, daegeum only]
merit stored in a barn grows less each time you count
an empty well always has fresh water
Because it has no substance
진공묘유
Seek the simple, face the hard, seek within
the more you give, the fuller it gets

[Chorus]
Merit has no substance
held, a handful, let go, the sky
with no vessel to contain it
it grows without an end
Merit has no substance
the more you give, the fuller it gets

[Outro]
[Chant, slow and low with fading moktak]
If merit were real, the Tathagata would not call it great
because merit has no substance, the Tathagata calls it great
```
