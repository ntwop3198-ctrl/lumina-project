# 새까맣게 타서 — KO·ZH·EN·JA·VI Suno 붙여넣기

곡 설명 칸은 비운다. **4-1 고향·향수.**
브리지 5줄째 **구소구고구기, 밖에서 찾지 않고**는 다섯 버전 모두 한글 그대로.
진공묘유는 넣지 않는다. 한자·영역·한월음으로 풀지 않는다.

## KO · 새까맣게 타서

```
새까맣게 타서
```

```

[Verse 4]
도라지는 보라 꽃을 보고 찾는 거라 하시고
더덕은 구수한 냄새가 난다 하시고
나는 배운 것도 없이 따라만 다녔는데
지금 와서 보니 그게 배운 거였네

[Chorus]
새까맣게 타서 집에 갔네

보라 꽃 하나로 찾던 도라지
작은 것 하나에도 길이 있었고
껍질 벗겨진 아린 등도 외면하지 않았네

그 여름은 아직 내 안에 있네

산에는 같이 갈 사람이 없네
```
