## 013 남의 시계

001이 선점한 「천천히」를 되풀이하지 않는다.  
005 V1 「남들의 시계에 내 하루를 맞추다」는 **한 행**이었다. 이 곡이 그 자리를 가져간다.

| 항목 | 잠금 |
|------|------|
| **장면** | 단톡의 벌써 · 옆자리 진도 · 누가 먼저 도착했다는 숫자. 플랫폼 실명 **금지** |
| **상처** | 비교가 내 하루를 **설명**하는 척한다 |
| **금지 훅** | 천천히 가도 돼 · 뒤처진 게 아니야 · 서툴러도 · 나만의 속도로 |
| **금지 소품** | 거울(004) · 명찰·등수(007) · 키(006) · 성적표(#36) |
| **출구** | **없음** — 012가 유머로 쉬었다. 설교 한 줄을 바로 얹지 않음 |
| **1388** | 없음 |
| **006과 갈림** | 006 「옆자리에 물어봤어」는 **사람**에게 물음. 013은 **타임라인**을 자로 댐 |
| **001과 갈림** | 001은 계절·자책 해제. 013은 비교라는 **행동** |

훅 후보: **남의 시계를 내 손목에 채우지 마** / **그 시계는 내 손목이 아니야**

Style 시드: `K-indie guitar pop, restless midtempo, clean chorus guitar, tight drums, clear female youth vocal, 118 bpm, Korean only`

## 014 처음 해본 거절

012가 어른 **연기**를 내려놓았다. 그다음 기술은 가짜 쿨이 아니라 **진짜 아니오**다.  
011은 오래 해온 **배역**을 그만두는 곡. 014는 들어오는 요청 **하나**를 거절하는 곡.

| 항목 | 잠금 |
|------|------|
| **장면** | 조별 떠넘김 · 야자 추가 · 「너만 믿어」. **가족 거절 금지** (56~70 보전) |
| **결론** | 거절해도 관계는 한 번에 끝나지 않는다. 고립을 답으로 두지 않음 |
| **금지** | 가면(#78) · 배역·무대(011) · 말해도 돼 설교 · 혼자 버티기 |
| **출구** | 거절 **자체가 실행**. 전화·물어보기 재탕 없음 |
| **1388** | 없음 |
| **자립≠고립** | 「거절 = 혼자」로 닫지 말 것. 「거절해도 나는 그 자리에」 |

훅 후보: **처음 해본 거절** / **오늘은 아니야 그 말 한 줄**

Style 시드: `Dry indie pop, spare electric piano, muted bass, quiet male youth vocal, taut chorus, 96 bpm, Korean only`

## 015 내가 고른 하나

성장·정체성 15칸의 종결. **다 컸다**도 **완성**도 아니다.  
010 Outro 「오늘은 여기까지 왔어」·「오늘 답을 내지 않아도 돼」를 제목·훅으로 쓰지 않는다.  
스케치북의 쉼표·마침표는 보류 칸(`lumina-youth-unfinished-is-ok-held.md`)에 둔다.

| 항목 | 잠금 |
|------|------|
| **장면** | 동아리 · 책 · 길 · 남는 자리. **고른 대상은 하나.** 목록 나열 금지 |
| **결론** | 나는 누구냐의 답을 닫지 않는다. **오늘 고른 하나**가 지금의 이름이다 |
| **금지 훅** | 다 컸다 · 온전한 나 · 진짜 나로 선다 · 빛나는 · 피어나다 · 빈칸 · 물음표 |
| **012와 갈림** | 012 딸기 라떼는 **허세 하차**. 015는 취향 유머가 아니라 **칸을 닫는 선택** |
| **003과 갈림** | 003은 나답게라는 **숙제**(추상). 015는 **고른 구체 하나** |
| **011과 갈림** | 011 「한 장면만 다르게」는 배역. 015의 하나는 **고름** |
| **출구** | **없음** — 선반을 설교로 닫지 않음 |
| **1388** | 없음 |
| **구소 챈트** | **미삽입** |

훅 후보: **내가 고른 하나** / **오늘 고른 게 지금의 나야**

Style 시드: `Warm indie pop, soft acoustic and electric blend, gentle tambourine, clear female youth vocal, unforced closer, 102 bpm, Korean only`

## 초안 받을 때

1. 세 곡을 **한 묶음**으로 받을 것. 013만 먼저 잠그면 014·015가 다시 겹친다.  
2. 제목은 위 셋이 기본. 바꾸려면 **빈 영역**이 같은지 먼저 볼 것.  
3. 009 「첫 알바비」 멘티 초안이 오면 **009를 먼저** 판교해도 된다. 013–015 프레임과 충돌하지 않음.  
4. 009 시드의 「어른 흉내는 내지 않을게」는 삭제됨. 012 전유.
