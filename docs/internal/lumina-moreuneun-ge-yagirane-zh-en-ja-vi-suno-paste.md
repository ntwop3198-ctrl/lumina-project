# 모르는 게 약이라네 — KO·ZH·EN·JA·VI Suno 붙여넣기

곡 설명 칸은 비운다. **5-2 성인 유머.**
브리지 5줄째 **구소구고구기, 밖에서 찾지 않고**는 다섯 버전 모두 한글 그대로.
진공묘유는 넣지 않는다.
