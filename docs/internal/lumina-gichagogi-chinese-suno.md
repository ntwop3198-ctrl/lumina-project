## Lyrics (v1)

```
[Verse 1]
把裤脚卷了一圈又一圈
光脚踩进石滩的凉水里
银色的阳光碎在水面上
细沙在脚趾缝里痒痒的

[Pre-Chorus]
小心地翻开一块石头
那家伙一下钻进了沙里
两只手合拢 屏住气等着
一眨眼的工夫 轻轻捧起来

[Chorus]
身子两边 一排小小的窗
你要跑去哪里 小火车鱼
每一格窗里 装着那时的梦
跟着浅滩水声 咣当咣当流走

[Verse 2]
空汽水瓶 装满清清的水
小心放进去 对着太阳看
一串串小小的黑点
就像跑着的火车车窗
你和我对望着 不出声地笑

[Bridge]
晚霞把天边染红的时候
放回浅滩 跟它说再见
指尖留下 一滴凉凉的水
舍不得也挥挥手 明天再见
구소구고구기, 밖에서 찾지 않고
多少年过去 那一天也不褪色

[Chorus]
身子两边 一排小小的窗
你要跑去哪里 小火车鱼
每一格窗里 装着那时的梦
跟着浅滩水声 咣当咣当流走

[Outro]
劈开水波 跑吧小火车
跑回想念的那条小溪
跑进我心里的浅滩
```
