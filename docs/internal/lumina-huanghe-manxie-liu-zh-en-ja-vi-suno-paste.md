# 황하야 좀 천천히 흘러 — KO·ZH·EN·JA·VI Suno 붙여넣기

곡 설명 칸은 비운다. **6-2 기록·증언.**
원곡 ZH 브리지 5줄째는 **求小求苦求己, 不向外求** 한자 그대로. KO·EN·JA·VI 브리지 5줄째는 **구소구고구기, 밖에서 찾지 않고** 한글.
진공묘유는 넣지 않는다. 한자·영역·한월음으로 풀지 않는다. 원문 괄호는 번역하지 않는다.
