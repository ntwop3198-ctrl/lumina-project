```
Errenzhuan, roomy vocal-and-instrument bleed, brisk 122 BPM syncopated clapper groove, warm mid-range comedic male-female call-and-response with backing voices and rapid theatrical patter, piercing festive suona lead, rapid banhu fiddle, bamboo clappers, Korean only
```
