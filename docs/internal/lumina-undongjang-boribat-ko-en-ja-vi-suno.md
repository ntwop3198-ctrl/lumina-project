# 운동장 보리밭 — 한국어·영어·일본어·베트남어 수노 붙여넣기

> **5-2 성인 유머** · 운동장 보리밭 · 남성
> 수노 제목은 업로드대로 `操场上的麦田`이다. 곡 설명 칸은 비운다.
> 다양성은 휴대폰 화면 정상, 노트북 화면 보통. 개인화는 끔.

하룻밤 초록은 물감이라는 풍자다. 불교 곡이 아니라 브리지 6행에 진공묘유를 넣지 않는다. 5행만 언어별 시그니처다. 중국어 가사는 업로드에 없어 넣지 않았다.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 칸 | `5-2 성인 유머`. 보여 주기 위한 보리밭을 비웃는 곡 |
| 브리지 | 6줄. 1·2행은 밤중에 봄을 칠하는 말. 3행은 문 앞 작은 마당. 4행은 손에 묻은 물감을 피하지 않음. 6행은 물통을 두고 마당을 쓰는 행동 |
| 브리지 5행 | 한국어 `구소구고구기, 밖에서 찾지 않고` · 영어 `Seek the simple, face the hard, seek within` · 일본어 `小を求め 苦を求め 己を求め, 外に求めず` · 베트남어 `Cầu điều giản dị, đương đầu gian khó, tìm trong chính mình` |
| 진공묘유 | 넣지 않음 |
| 기호 | 가사 칸에 괄호, 따옴표, 느낌표, 말줄임표, 쉼표 없음. 시그니처 쉼표만 유지 |
| 영어 | 아포스트로피와 줄임말 없음. dead of night는 밤중으로 바꿈 |
| 화자 | 부르는 칸 아래 `[Male]`. 빈 인터루드에는 없음 |
| 다음 아침 | 해가 뜨면 운동장이 빈다는 이야기는 풍자의 결이라 남김 |

업로드의 놀자는 이미 `lumina-nolja-zh-en-ja-vi-suno.md`에 있어 여기서 다시 쓰지 않았다.
