# 장자 연작 — 중국어·영어 수노 붙여넣기

> **7-2 도교·유교** · 장자 연작 20곡
> 수노 곡 설명 칸은 비운다. 스타일 칸은 업로드본 그대로 둔다.
> 홀수 곡은 여성, 짝수 곡은 남성이다.
> 다양성은 휴대폰 화면 정상, 노트북 화면 보통. 개인화는 끔.

불교 곡이 아니다. 브리지 6행에 진공묘유를 넣지 않는다. 5행만 언어별 시그니처다.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 칸 | 20곡 모두 `7-2 도교·유교`. 도교와 유교를 나누지 않음 |
| 브리지 | 6줄. 1·2행은 그 곡의 말. 3행은 그 곡의 작은 것, 4행은 피하지 않는 고생. 6행은 그 곡의 다음 행동 |
| 브리지 5행 | 중국어 `求小求苦求己, 不向外求` · 영어 `Seek the simple, face the hard, seek within` |
| 진공묘유 | 넣지 않음. 7-1 불교 곡이 아님 |
| 한글 시그니처 | 가사에는 넣지 않음. 한글로 통일할 때만 5행을 `구소구고구기, 밖에서 찾지 않고`로 바꾼다 |
| 기호 | 가사 칸에 괄호, 따옴표, 느낌표, 말줄임표, 쉼표 없음. 시그니처 쉼표만 유지 |
| 영어 | 아포스트로피 없음 |
| 화자 | 부르는 칸 아래 `[Female]` 또는 `[Male]`. 연출 태그와 악기 페이드, `[Fade Out]`에는 없음 |
| 01 | 구만 리의 붕은 이야기의 새로 둠. 가로막는 것이 없다는 말은 옆에서 부는 바람으로 낮춤 |
| 03 | 한평생을 온전히 산다는 말은 이 계절로 낮춤. 무하유지향의 그늘은 둠 |
| 07 | 소 수천 마리와 칼, 뼈마디는 가사에서 빼고 결의 빈틈으로 둠. 제목의 포정 이야기는 둠 |
| 09 | 빈 방에서 흰 빛이 나고 천하가 깃든다는 말은 이 한 숨으로 낮춤 |
| 10 | 걸림 없는 하늘과 큰길에 녹아든다는 말은 이 자리에 앉는 것으로 낮춤. 앉아서 잊는 실천은 둠 |
| 12 | 물고기 즐거움은 마음속이 아니라 이 다리 위에서 안다고 둠 |
| 13 | 마른 뼈와 빈 뼈다귀는 빈 껍질과 진흙 속 꼬리로 바꿈. 죽음이라는 낱말은 넣지 않음 |
| 17 | 세상 전체가 넓어도 놓치지 않는다는 말은 매미 날개 하나로 둠 |
| 18 | 일곱째 날 혼돈이 스러지고 숨을 빼앗긴다는 말은 결이 흐트러지는 이야기로 낮춤 |
| 19 | 동이를 두드리며 노래하는 작별은 둠. 죽음이라는 낱말은 넣지 않음 |

12곡은 업로드 문서의 子非鱼다. 채팅 초안의 제목 桥上的鱼와 마음에서 안다는 풀이, 바이올린은 넣지 않았다. 01부터 20을 한 연작으로 넣었다. 악기는 곡마다 업로드본을 따른다. 중국어판은 구정, 동소, 얼후가 섞여 있고, 영어판은 가야금, 대금, 해금이다.
