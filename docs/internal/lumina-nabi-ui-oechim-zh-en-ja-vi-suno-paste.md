# 蝴蝶的呼喊 — KO·ZH·EN·JA·VI Suno 붙여넣기

곡 설명 칸은 비운다. 브랜드송 해당 없음.  
브리지 **구소구고구기** · **진공묘유**는 다섯 버전 모두 한글 그대로. 한자·영역·한월음으로 풀지 않는다.  
원문 6줄 브리지. Gemini 시그니처 `구소구고구기, 밖에서 찾지 않고`로 바꾸지 않는다.  
괄호 연주 지시는 영어 메타데이터.
