# 구로망기 — 중국어·영어 수노 붙여넣기

> **7-1 불교** · 진공묘유 · 구소구고구기  
> 수노 곡 설명 칸은 비운다.  
> 보컬은 남성. 다양성은 정상, 개인화는 끔.

갈매기·해오라기 장면은 옛 이야기에서 가져왔다. 브리지에 진공묘유를 부르고 끝에서 무사인(无事人)을 말하므로 칸은 7-1 불교로 둔다.

호흡은 한 숨에 부를 수 있는 짧은 줄이다. 템포는 72 BPM.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 브리지 | 6줄. 3행 求小, 4행 求苦 |
| 브리지 5행 | 중국어 `求小求苦求己, 不向外求` · 영어 `Seek the simple, face the hard, seek within` |
| 브리지 6행 | `真空妙有` · `True emptiness, wondrous being` |
| 한글 시그니처 | 가사에는 넣지 않음. 한글로 통일할 때만 5행을 `구소구고구기, 밖에서 찾지 않고`로 바꾼다 |
| 괄호 · 따옴표 · 느낌표 | 가사 블록에 없음. 연출은 영어 대괄호만 |
| 검사어 | 칼 · 피 · 죽음은 다른 말로 옮김 |
| 화자 | 각 섹션 아래 `[Male]` |

초안의 시그니처는 브리지 1행에 있었다. 5행으로 옮겼다. `真空妙유`는 `真空妙有`. `Vacuum and marvelous being`은 `True emptiness, wondrous being`.

## 붙여넣기 순서

각 언어마다 수노 칸은 네 개다.

1. 곡 설명은 비운다.
2. 제목 코드 블록.
3. 스타일 코드 블록.
4. 제외 코드 블록.
5. 가사 코드 블록.

5행을 한글로 통일할 때만 `구소구고구기, 밖에서 찾지 않고`로 바꾼다. 중국어 줄과 영어 줄을 함께 넣지 않는다.
