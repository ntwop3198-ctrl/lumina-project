## Title

```
버들피리
```

원곡. 보컬 **남성** — 맑고 담백한 톤, 봄 물가를 떠올리듯 느긋하게

---

## Style

```
Korean folk ballad, gentle acoustic guitar, warm strings, soft flute, pastoral and nostalgic, unhurried mid-tempo, clear male vocal, springtime mood, 74 BPM, Korean only
```

## Exclude Styles

```
EDM, rap, autotune, female vocal, choir, epic orchestra, trot vibrato, fast dance beat, tragic mood, heavy reverb, English vocals
```

## Lyrics (v1)

```
[Verse 1]
물이 오른 버들가지
톡톡 두드려 달래고
살짝 비틀어 빼내면
그게 우리 피리였지

[Verse 2]
길게 자르면 낮은 소리
짧게 자르면 높은 소리
누구 소리가 더 맑은가
물가에 앉아 겨루었지

[Pre-Chorus]
봄 한철에만 나던 소리
계절 지나면 굳던 소리
그때는 몰랐네
아무 때나 부는 줄 알고

[Chorus]
삐리리 삐리리
버들피리 부는 소리
개울물 소리에 실려서
멀리도 갔었지
삐리리 삐리리
그 봄날 그 물가에

[Verse 3]
터져 버리면 또 만들고
잃어버리면 또 꺾고
아까울 게 없었네
버들은 늘 거기 있으니

[Bridge]
지금도 그 자리에
버들은 서 있을까
가지 하나로 봄을 불던 아이
굳어 버린 계절도 탓하지 않았지
구소구고구기, 밖에서 찾지 않고
서 있다 한들 이제 꺾을 손이 없네

[Chorus]
삐리리 삐리리
버들피리 부는 소리
개울물 소리에 실려서
멀리도 갔었지
삐리리 삐리리
그 봄날 그 물가에

[Outro]
삐리리 삐리리
```
