## Lyrics (v1)

```
[Intro]
[Low cello]
隠せば消えると思っていた

[Verse 1]
人前では傷のない顔で
きれいなふりをして生きた日々があった
心の中では別のものが煮えているのに
表では何でもないふりで笑っていた

[Verse 2]
隠しても火が消えるわけじゃない
荷はいつも二重に積もっていく
ひとつはその心そのものの重さ
ひとつは見抜かれまいとしがみつく重さ

[Pre-Chorus]
表と裏が長く分かれていると
その重さを体は知らないふりをしない
冷える節々 遅くなる息
隠した歳月が跡になって残ることもある

[Chorus]
欲は隠れるための壁じゃなかった
向き合えばかえって軽くなれたのに
隠すことに使い果たしたその力
整えることに使っていたなら
隠すことの重さが私を押しつぶした

[Verse 3]
誰かをだましたようでも
いちばん長くだましたのは自分だった
口は黙っていられても
息は嘘を長く隠せない

[Bridge]
何をそんなに隠そうとしていたのか
隠したものを下ろして自分に問いかける
人の目ではなく自分の内を見る
空いた場所で息が少しひらく
小を求め 苦を求め 己を求め, 外に求めず
軽くなった足取りでまた歩いていく

[Chorus]
欲は隠れるための壁じゃなかった
向き合えばかえって軽くなれたのに
隠すことに使い果たしたその力
整えることに使っていたなら
隠すことの重さが私を押しつぶした

[Outro]
[Lingering cello]
隠そうとしたあの影が
私をいちばん重くしていた
```
