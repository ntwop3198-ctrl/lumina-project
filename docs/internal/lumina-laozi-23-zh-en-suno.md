# 노자 연작 — 중국어·영어 수노 붙여넣기

> **7-2 도교·유교** · 노자 도덕경 연작 23곡
> 수노 곡 설명 칸은 비운다. 스타일 칸은 업로드본 그대로 둔다.
> 짝수 곡은 여성, 홀수 곡은 남성이다.
> 다양성은 휴대폰 화면 정상, 노트북 화면 보통. 개인화는 끔.

불교 곡이 아니다. 브리지 6행에 진공묘유를 넣지 않는다. 5행만 언어별 시그니처다.

## 적용한 규칙

| 항목 | 처리 |
|------|------|
| 칸 | 23곡 모두 `7-2 도교·유교`. 도교와 유교를 나누지 않음 |
| 브리지 | 6줄. 1·2행은 그 곡의 말이나 경의 구절. 3행은 그 곡의 작은 것, 4행은 피하지 않는 고생. 6행은 그 곡의 다음 행동 |
| 브리지 5행 | 중국어 `求小求苦求己, 不向外求` · 영어 `Seek the simple, face the hard, seek within` |
| 진공묘유 | 넣지 않음. 7-1 불교 곡이 아님 |
| 한글 시그니처 | 가사에는 넣지 않음. 한글로 통일할 때만 5행을 `구소구고구기, 밖에서 찾지 않고`로 바꾼다 |
| 기호 | 가사 칸에 괄호, 따옴표, 느낌표, 말줄임표, 쉼표 없음. 시그니처 쉼표만 유지 |
| 영어 | 아포스트로피 없음 |
| 화자 | 부르는 칸 아래 `[Female]` 또는 `[Male]`. 연출 태그와 악기 페이드, `[Fade Out]`에는 없음 |
| 경 구절 | 道可道, 有无相生, 谷神不息, 三十辐, 上善若水, 天下莫柔弱于水, 知足不辱, 为学日益, 曲则全, 天下莫能与之争, 企者不立, 自知者明, 大器晚成, 祸兮福之所倚, 天下难事必作于易, 天将救之 以慈卫之, 不敢为天下先, 天网恢恢, 小国寡民, 信言不美는 원문 그대로 |

| 05 | 물이 바다가 되고 가장 높은 길이라는 말은 한 웅덩이와 한 치로 낮춤 |
| 07 | 천 년의 돌, 절벽을 갈아내고, 세상에서 가장 강하다는 말은 돌 위의 한 방울로 낮춤. 弱之胜强은 둠 |
| 11 | 오래 평안하고 이미 충분하다는 말은 이 한 숨으로 낮춤. 知足不辱은 둠 |
| 12 | 빈자리에 봄이 온다는 말과 날마다 가벼워진다는 말은 이 한 몫과 이 하루로 낮춤. 无为而无不为는 둠 |
| 13 | 세상과 겨뤄 이길 사람이 없다는 결과는 경의 구절로 두고, 행동은 허리 한 번 굽히는 것으로 둠 |
| 16 | 바다를 담는 그릇과 반드시 깊은 그릇이 된다는 말은 한 웅덩이와 가마의 기다림으로 낮춤 |
| 19 | 天将救之 以慈卫之는 경의 구절로 둠. 가장 든든한 방패와 모든 이의 어른이 된다는 말은 한 걸음 양보로 낮춤 |
| 21 | 그물을 빠져나가지 못하고 하늘이 다 본다는 말은 이 한 걸음을 보는 것으로 낮춤. 天网恢恢 疏而不失은 둠 |
| 22 | 날마다 풍족하고 평안이 머문다는 말은 집의 한 그릇으로 낮춤 |

채팅에 붙은 14부터 23의 초안은 쓰지 않았다. 번체와 구정, 얼후, 피아노는 넣지 않았다. 01부터 13도 업로드 문서에 있어 스물세 곡을 한 연작으로 넣었다. 악기는 업로드본의 거문고, 가야금, 대금, 해금, 장구, 피리를 곡마다 그대로 둔다.
