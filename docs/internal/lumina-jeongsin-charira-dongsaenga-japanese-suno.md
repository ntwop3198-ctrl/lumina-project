## Lyrics (v1)

```
[Intro]
[Acoustic Guitar]
[Harmonica]

[Verse 1]
酒の前でだけ 大口をたたいて
拳の話で 夜を明かす
兄貴を助けると 口では言うけど
勘定はいつも 俺の役

[Verse 2]
その日が過ぎれば 全部忘れて
次の日もまた 同じ席
わかっているだろう お前の役目だと
わかっていて なぜまたその席に

[Pre-Chorus]
お前が憎くて 言うんじゃない
今日は俺も 少し疲れた

[Chorus]
しっかりしろよ 弟よ
兄貴ももう疲れた
お前のそばに 残った人たち
ひとりふたりと 去っていく
手を差し伸べた人に
拳をあげるな
みんな去ってしまったら
誰がお前を呼ぶだろう

[Interlude]

[Verse 3]
小銭を握らせても その日で終わり
だから今度は 渡さない
自分の手で 部屋ひとつ見つけたら
その時は 俺が先に行く

[Bridge]
兄貴には 手を出せないと
そっと背を向けた お前
その気持ちひとつ 残っていれば
まだ遅くはない
구소구고구기, 밖에서 찾지 않고
お前の道は お前が探せ

[Final Chorus]
しっかりしろよ 弟よ
兄貴ももう疲れた
お前のそばに 残った人たち
まだ待っている
手を差し伸べた人に
ありがとうと言え
その一言でいい
そこからまた始めろ

[Outro]
しっかりしろよ 弟よ
兄貴はここにいる
[Fade Out]
```
