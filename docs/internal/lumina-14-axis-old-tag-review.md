## 같이 고친 것

1. 「스무 살의 문 앞에서」 가사 시그니처는 **구소구고구기** · **진공묘유**. 단어는 빼지 않음.
2. 위 곡 문서의 「1-3 없음」「6-1 없음」「7-1 없음」「13 없음」 문장은 지움.
3. `lumina-suno-title-list-axis1.md`의 「1-3은 없다」 줄을 지움.
4. **1-3이 열렸다고 4-2를 비우지 않는다.** 4-2 안부·요청곡은 실제 특정인을 두고 만들었거나 부탁받은 곡의 자리. 가사에 「너」나 「당신」이 있다는 것만으로 4-2에 넣지 않는다.

일산 가는 길 · 판다야 울지마 · 구름과 물결처럼 · 장길아 정신차리라는 **4-2** 그대로.
