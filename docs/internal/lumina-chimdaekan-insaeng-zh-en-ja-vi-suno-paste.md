# 卧铺人生 — ZH·EN·JA·VI Suno 붙여넣기

곡 설명 칸은 비운다. 브랜드송 해당 없음.  
브리지 6줄. 5행은 언어 시그니처. **진공묘유 없음.**  
VI 5행은 KO `구소구고구기, 밖에서 찾지 않고` (VI 시그니처 미잠금).  
JA 스타일은 **enka-style trot**. 제외 칸에 enka를 넣지 않는다.  
VI 스타일은 **bolero-style trot**. 가야금·아코디언은 네 버전 모두 유지.
