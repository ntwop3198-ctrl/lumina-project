## Style

```
Polka, warm male vocal with playful phrasing, dry mono studio mix, accordion leading over oom-pah tuba, bright banjo and crisp handclaps, brisk bouncing pulse with a half-time bridge and a lively finish, English vocals, short Korean chant in bridge
```

## Exclude Styles

```
EDM, trap, rap, autotune, metal, screaming, sad ballad, female vocal
```

고급 설정: 기이함 **30%** · 스타일 영향 **70%** · 다양성 보통 · 개인화 끔
