## Lyrics (v1)

```
[Intro]
[Guqin]
[Dizi]
[Spoken]
興凱の水は空に続き 境の湖に稲の香り
葦に水鳥が舞い ひとすじの水が朝日を映す

[Verse 1]
興凱湖のほとり 沃野は広く
葦の茂みに 百の鳥が鳴く
両岸の平野 千里の緑
ひとすじの碧水 空を映す

[Pre-Chorus]
密山と虎林 寄りそいつらなり
黒い大地が 良い田を育てる
代々 漁と耕しで 風雨をこえ
千重の波が 胸にゆれる

[Chorus]
興凱湖 広い境の湖
果てない碧水 雲に届く
静けさに甘んじ 葦にかくれ
ひとふしの漁歌 年々に

[Verse 2]
大きな湖は果てなく 小さな湖が寄りそい
数えきれない渡り鳥 夕焼けと帰る
夕べの漁舟 遠い帆が戻り
ひとつの伝えが 代々続く

[Pre-Chorus]
密山と虎林 寄りそいつらなり
千里の沃野に 稲の花の香り
耕しつづけて 遠くへゆく
心やすらぐ ここがふるさと

[Chorus]
興凱湖 広い境の湖
果てない碧水 雲に届く
静けさに甘んじ 葦にかくれ
ひとふしの漁歌 年々に

[Bridge]
湖の光は黙って 空に続き
自分の力で立ち 腰を折らない
頭を下げて湖を耕し 小さきを敬い
風霜雨雪に 苦労を飲みこむ
구소구고구기, 밖에서 찾지 않고
葦のほとりで 絶えることなく

[Final Chorus]
興凱湖 万代に香る
碧水は黙って 千の夢を受け
代々耕して 初心を守り
ひろがる湖の光 とこしえに

[Outro]
葦のほとり 水と空は果てなく
境の湖は広く 遠く長く流れる
[Fade Out]
```
