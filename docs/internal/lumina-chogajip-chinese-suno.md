## Style

```
Chinese folk ballad, warm acoustic guitar, gentle daegeum flute, soft gayageum, sparse percussion, aged warm male vocal, nostalgic and earthy, rural home mood, 68 BPM, Mandarin vocals, short Korean chant in bridge
```

## Exclude Styles

```
EDM, rap, autotune, female vocal, choir, epic orchestra, trot vibrato, fast dance beat, tragic mood, heavy reverb
```

## Lyrics (v1)

```
[Verse 1]
稻草编起来 盖成的屋顶
年年都要 再添一层
漏雨的地方 修修补补
不知不觉 秋天就深了

[Verse 2]
清早灶膛里 添上木柴
铁锅先叮当 响起来
土墙那边 烟囱上头
青烟直直地 升起来

[Pre-Chorus]
母亲在灶间忙着
父亲在院子里转着
我坐在磨亮的门槛上
把那一天 全都看着

[Chorus]
茅草屋 那座屋
如今不在的 那座屋
烧稻草的 呛人晚烟味
大铁锅里 饭开的声音
茅草屋 那座屋
还在我心里 站着

[Verse 3]
矮矮屋檐下 旧燕子窝
每到春天 都不忘回来

燕妈妈 一趟一趟飞进飞出

[Bridge]

구소구고구기, 밖에서 찾지 않고
回去的路 就在我心里

那座屋
```
